# Форма обратной связи — «Конференции.РФ»

Практическая работа 2. Интерактивная форма обратной связи в виде модального окна для веб-приложения «Конференции.РФ». Форма открывается на странице просмотра заявок после завершения мероприятия.

## Компоненты

- `FeedbackModal.vue` — модальное окно с формой (оценка звёздами + комментарий), валидацией и адаптивной вёрсткой.
- `ToastNotification.vue` — всплывающее уведомление «Спасибо за отзыв!».

## Реализованный функционал

- Модальное окно с крестиком для закрытия.
- Оценка мероприятия — 5 звёзд (обязательное поле).
- Комментарий — многострочное поле, ограничение 500 символов со счётчиком.
- Валидация на стороне клиента: при отправке без оценки выводится сообщение об ошибке рядом с полем.
- Закрытие окна по клику на затемнённый фон (overlay) или по нажатию Esc.
- После успешной отправки: отзыв сохраняется, показывается toast «Спасибо за отзыв!», окно закрывается, на странице остаётся текст «Ваш отзыв отправлен».
- Адаптивность: корректное отображение на мобильных устройствах (390×844), окно занимает большую часть экрана и прокручивается, элементы увеличены для удобного нажатия пальцем.

## Технологии

- Vue 3 (Composition API, `<script setup>`)
- HTML5, CSS3 (scoped-стили, media-запросы)
- JavaScript (ES6+)
